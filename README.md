# architeam.me

Finished static build of the Architeam site (originally generated by Astro; the source is not in this repo, so these HTML files are the site). Every push to `main` is uploaded to Sprinthost by `.github/workflows/deploy.yml`.

- Blog sources and builder: `_blog/` (see `_blog/RUNBOOK.md`). Not uploaded to the server.
- Build: `python3 _blog/build.py --check`
- FTP password: repository Secret `FTP_PASSWORD`. Server folder: `domains/architeam.me/public_html/` (override with Variable `FTP_SERVER_DIR`).
- `send.php` (form handler with the Telegram bot token) lives only on the server and is never committed or uploaded.

- Analytics: Yandex Metrika 113803365, loaded only after cookie consent. Banner inserted by `_blog/consent.py` (re-run it if pages are regenerated).
