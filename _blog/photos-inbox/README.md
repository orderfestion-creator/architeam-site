# Photo inbox

Upload photos of real Architeam projects: renders, drawings, building sites, finished buildings here (GitHub: open this folder → Add file → Upload files).
Any JPG, PNG, WEBP or HEIC straight from the phone is fine; no need to rename or resize.

The next scheduled blog run converts them for the web (removes GPS/EXIF data, makes .webp in /img/blog),
describes what each photo shows in _blog/PHOTOS.md, deletes the originals from this folder,
and uses them in articles where they fit.

Only upload photos you are allowed to publish (no faces of clients, no house numbers or car plates you don't want online).
